# 00. 产业链总览

> 本章回答三个问题：为什么按 8 层切分？每一层解决什么？层与层之间的价值如何传导？

---

## 一、为什么是 8 层

多数券商研报只覆盖 **L1（零部件）→ L6（整机）**，把"机器人"理解为一台硬件机器。

具身智能的真正不同在于：**它是一台"硬件 + 模型 + 算力 + 数据"的复合体**。如果只看硬件，会漏掉整个 AI 时代最值钱的环节——基础模型与算力平台。

按 **资源 → 硬件 → 控制 → 算力 → 仿真 → 模型 → 整机 → 场景** 切分，可以把以下 5 类玩家全部纳入同一张图：

1. **传统工业自动化公司**（L1、L2）
2. **消费电子 / 汽车供应链**（L0、L1、L4）
3. **AI 基础设施公司**（L3、L4、L5）
4. **人形机器人初创公司**（L6）
5. **应用场景落地方**（L7）

---

## 二、8 层结构与价值传导

| 层级 | 名称 | 核心问题 | 谁来解决 | 价值特征 |
|------|------|----------|----------|----------|
| L0 | 资源材料层 | 电机/结构的物质基础从哪来？ | 稀土、碳纤维、锂电材料厂商 | 强周期、高弹性 |
| L1 | 核心零部件层 | 关节、传动、感知怎么做？ | 减速器、丝杠、电机、传感器厂商 | 产业链利润率最高 |
| L2 | 控制系统层 | 运动控制如何实时执行？ | 控制器、ROS、RTOS 厂商 | 国产替代进行中 |
| L3 | Robot Compute | 模型推理在哪跑？ | GPU / 机器人 SoC 厂商 | NVIDIA 寡头格局 |
| L4 | 仿真平台 | 机器人在哪训练？ | 数字孪生、Isaac、Cosmos、World Model | 数据飞轮起点 |
| L5 | VLA 基础模型 | 通用机器人大脑给谁做？ | VLA 模型公司 | 可能诞生千亿美元公司 |
| L6 | 机器人整机 | 谁把机器造出来？ | 工业 / 协作 / 人形机器人厂商 | 短期估值波动大 |
| L7 | 应用场景 | 机器人先去哪打工？ | 制造、仓储、商业、家庭、医疗 | ROI 决定落地速度 |

### 价值传导链

```
L0 资源涨价
  → L1 零部件成本压力
    → L6 整机 BOM 居高
      → L7 落地场景必须先选 ROI 清晰的（制造、仓储）
        → L4 仿真 + L5 模型加速数据积累
          → 长期反哺 L1 标准化、L3 算力下沉
```

**核心洞察**：在 2026-2028 的"破冰期"，**L1、L6、L7** 决定能不能卖出去；**L3、L4、L5** 决定能不能便宜地造出来并持续变聪明。**真正的复利从 L3-L5 开始。**

## 三、每一层的"赢家画像"

| 层级 | 赢家画像 | 类比 |
|------|----------|------|
| L0 | 拥有资源端定价权 | "机器人时代的沙特阿美" |
| L1 | 单项市占率全球前三 + 大客户绑定 | 苹果产业链 Tier 1 |
| L2 | 工业控制经验 + 机器人算法积累 | 发那科、库卡 |
| L3 | 通用 GPU + 机器人专用 SoC 双重布局 | NVIDIA、Qualcomm |
| L4 | 仿真 + 世界模型 + 训练数据三位一体 | Unreal Engine + OpenAI |
| L5 | VLA 模型 + 数据飞轮 + 顶级团队 | OpenAI、Anthropic |
| L6 | 自研核心部件 + 量产工厂 + AI 团队 | 特斯拉 |
| L7 | 场景理解 + 系统集成 + 客户关系 | 富士康、京东、亚马逊 |

## 五、与其他常见框架的对比

| 框架 | 切法 | 局限 |
|------|------|------|
| 传统券商 | L1 + L6 两层 | 漏掉 L3-L5 最值钱环节 |

## 六、关键名词速查

- **VLA**（Vision-Language-Action）：视觉-语言-动作多模态大模型，机器人时代"基础模型"的统称。
- **World Model**（世界模型）：对物理世界运行规律的概率建模，是 VLA 训练的"虚拟数据工厂"。
- **RV 减速器 / 谐波减速器**：工业机器人与人形机器人最常用的两类减速器，分别用于大负载关节与小体积高精度关节。
- **无框力矩电机**：去掉外壳、轴和轴承的力矩电机，专为人形机器人关节设计。
- **行星滚柱丝杠**：将旋转运动转为直线运动的精密传动件，Tesla Optimus 线性关节核心。
- **六维力传感器**：可同时测量三维力 + 三维力矩的高阶传感器，机械臂"触觉"。
- **灵巧手**：多自由度、带触觉感知的人形机器人末端执行器。
