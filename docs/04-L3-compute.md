# L3. Robot Compute

> 机器人时代的 GPU 层。AI 模型的训练与推理需要算力，机器人对算力的需求比传统 AI 更复杂——既要高吞吐训练，又要低延迟低功耗推理。

---

## 一、为什么 Robot Compute 是独立的一层

普通 AI 算力需求是 **"数据中心集中训练 + 云端推理"**。

机器人算力需求是 **"云端训练 + 边缘端实时推理"**：

- 训练：在数据中心跑（需要 H100 / Blackwell / B200 级别 GPU）
- 推理：在机器人本体跑（需要 Jetson Orin / Thor / 机器人专用 SoC）
- 仿真：在云端 + 边缘端跑（需要大量并行算力）

**核心矛盾**：机器人本体续航有限（电池容量 1-3 kWh），推理功耗必须控制在 **50-150W** 以内，同时还要支持 7B-13B 参数 VLA 模型实时推理。

**结论**：机器人对"低功耗高算力"芯片的需求，远超传统 AI 推理。

## 四、Qualcomm：高通在机器人边缘的"反击"

### 优势

- 长期深耕移动 SoC，功耗控制经验足
- 在异构计算（CPU + GPU + NPU + DSP）上经验丰富
- 与 Android 生态打通，开发者友好

### 机器人产品矩阵

| 产品 | 定位 | 应用 |

| SA8155P | 座舱域控 | 汽车向机器人外溢 |

### 投资逻辑

> 高通是 **"机器人时代的边缘推理挑战者"**——它不一定能颠覆 NVIDIA，但在对功耗极度敏感的移动机器人、无人机、消费级机器人领域有结构性机会。

## 五、AMD：机器人推理市场的"潜在受益者"

### 机会点

- GPU 训练端：MI300 系列在 H100 缺货时获得部分客户
- 边缘推理：与高通合作的 Kria K26 平台
- 自适应计算：Versal AI Edge 系列在机器人感知端

### 风险

- 机器人专用工具链（CUDA 的替代）不成熟
- 生态薄弱，难以与 NVIDIA 抗衡

### 投资逻辑

> AMD 是 **"如果 NVIDIA 出问题"** 的对冲选项。在机器人时代，AMD 仍属"备选"而非"主选"。

## 十二、风险点

1. **NVIDIA 估值高位**：当前市值已透支多年预期。
2. **国产替代节奏**：训练端替代难，推理端替代容易。
3. **技术路线变化**：神经拟态芯片、存内一体计算可能颠覆 GPU 架构。
4. **地缘政治**：H100 / Blackwell 对中国出口受限，影响国内厂商路径。

---

## 十三、小结

- L3 是 **"全球最确定的机器人卖铲人"**——NVIDIA 几乎无法被绕过。
- A 股投资者通过 **服务器代工、光模块、PCB** 间接受益于 NVIDIA 算力扩张。
- 真正的弹性来自 **"机器人本体放量 → 边缘 AI 芯片需求"** 的二阶导——这是 2027 年后的故事。
