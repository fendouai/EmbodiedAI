# L6. 机器人整机层

> 谁会造出机器人时代的"特斯拉"？这一层是 **品牌 + 制造 + 供应链 + AI 团队** 的综合较量。

## 八、投资逻辑

> L6 是 **"高弹性 + 高波动"** 的环节——整机公司股价对销量数据极其敏感。

**美股**：

- **Tesla**（确定性最高，但估值已包含预期）
- **Figure AI**（未上市，估值 400 亿美元）
- 通过 **Agility 母公司 Amazon** 间接参与

**港股**：

- **优必选**（9880.HK）：人形机器人第一股
- 比亚迪（1211.HK）：通过智元机器人 + 自研机器人布局

**A 股**：

- 关注 **宇树、智元、银河通用** 的产业链上游（电机、减速器、传感器）
- 关注 **优必选供应链**（汇川、埃斯顿、绿的谐波）
- 关注 **比亚迪、立讯精密**（机器人 + 智能制造协同）

## 九、风险点

1. **量产时间表反复推迟**：人形机器人技术难度高，可能 2027-2028 才能规模量产。
2. **价格战风险**：宇树 9.9 万元打开了降价空间，可能压缩其他玩家利润。
3. **AI 路线分歧**：端到端 VLA vs 分层控制 vs 行为克隆，胜出者未定。
4. **客户场景验证**：工厂落地案例是真正决定股价的关键。
5. **估值泡沫**：一级市场估值高企，二级市场可能面临估值回归。

## 十、整机公司的"赢家画像"

> **能成为"机器人时代的苹果"的玩家，必须同时具备 5 项能力**：

1. **硬件自研**（电机、减速器、控制器、传感器）
2. **AI 团队**（VLA 模型 + 数据闭环）
3. **垂直整合**（自研芯片、电池）
4. **超级工厂**（大规模量产能力）
5. **品牌 + 客户**（强势应用场景）

**目前最接近这个画像的**：

- Tesla
- Figure AI
- 优必选
- 智元机器人（部分）

---

## 十一、小结

- L6 是 **机器人产业链的"品牌 + 流量入口"**——整机公司是公众认知和资本叙事的主角。
- 真正的赢家会从 **Tesla、Figure、宇树、优必选、智元** 中诞生。
- A 股投资者最稳妥的策略：**通过上游零部件（L1）和供应链协同方（如立讯精密、比亚迪）参与**，规避整机公司的高估值波动。
