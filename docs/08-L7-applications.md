# L7. 应用场景层

> 机器人最先在哪些场景落地？哪些场景能算出 ROI？哪些场景是"诗和远方"？

---

## 一、应用场景分级

| 等级 | 场景 | ROI 清晰度 | 落地时间 | 市场天花板 |
|------|------|------------|----------|------------|
| ★★★★★ | 制造业 | 极高 | 已大规模 | 大 |
| ★★★★★ | 物流仓储 | 极高 | 已规模化 | 大 |
| ★★★★ | 商业服务 | 高 | 已商业化 | 中 |
| ★★★ | 医疗护理 | 中 | 2027-2030 | 大 |
| ★★ | 家庭服务 | 低 | 2030+ | 极大 |
| ★ | 军事 / 特种 | 国防需求 | 持续 | N/A |

---

## 二、制造业

### 典型场景

- 汽车装配（焊接、喷涂、搬运）
- 3C 电子组装（精密装配、检测）
- 金属加工（上下料、机加工）
- 食品包装

### 代表企业

| 企业 | 国家 | 方向 |
|------|------|------|
| Tesla | 美国 | Optimus 进入自家工厂 |
| BMW | 德国 | 与 Figure 合作 |
| Mercedes-Benz | 德国 | 与 Apptronik 合作 |
| Foxconn（富士康） | 中国 | 工厂机器人 + 人形机器人 |
| 比亚迪 | 中国 | 工厂人形机器人（自研） |
| 三星 | 韩国 | 工厂机器人 |

### 为什么最先落地

> **制造业是 ROI 最清晰的场景**——固定工位、重复动作、明确产出、易于安全管控。

**关键指标**：

- 单台机器人替代 1-2 个工人
- 投资回收期 < 2 年
- 24×7 不间断工作
- 工伤率下降

---

## 三、物流仓储

### 典型场景

- 分拣（Sorting）
- 搬运（Picking & Placing）
- 配送（Last Mile）
- 库存盘点

### 代表企业

| 企业 | 国家 | 方向 |
|------|------|------|
| Amazon | 美国 | Kiva + Agility Digit + Proteus |
| 京东 | 中国 | 物流 AMR + 配送机器人 |
| 顺丰 | 中国 | 无人配送 + 仓储自动化 |
| 菜鸟 | 中国 | 仓储机器人 |
| DHL | 德国 | 仓储自动化 |
| 联邦快递 | 美国 | 自动配送 |

### ROI 逻辑

> **物流是工业之外，ROI 第二清晰的场景**——订单明确、流程标准化、可量化。

**关键指标**：

- 分拣效率提升 3-5 倍
- 错误率下降 90%
- 24×7 运营
- 应对电商大促弹性

### 中国玩家

| 公司 | 方向 | 状态 |
|------|------|------|
| 极智嘉（Geek+） | 仓储 AMR | 已上市 |
| 海康机器人 | AGV + 机器视觉 | 拟分拆上市 |
| 旷视科技 | 仓储 + 物流 | 港股上市 |
| 快仓 | 仓储机器人 | 拟上市 |
| 灵动科技 | 视觉 AMR | 早期 |
| 凯乐士 | 物流机器人 | 早期 |

## 四、商业服务

### 典型场景

- 餐厅送餐
- 酒店服务
- 商场导览
- 清洁
- 巡检

### 代表企业

| 企业 | 方向 |
|------|------|
| 普渡科技 | 餐厅配送机器人 |
| 擎朗智能 | 餐厅 + 酒店 |
| 云迹科技 | 酒店服务机器人 |
| 高仙 | 商用清洁机器人 |
| 国自机器人 | 巡检 + 物流 |

### ROI 逻辑

> 商业服务场景的 ROI 来自 **"人工成本 + 标准化服务"**——但单台价格必须低（< 5 万元）。

**关键约束**：

- 价格必须 < 5 万元
- 维护成本低
- 与现有管理系统集成

## 五、医疗护理

### 典型场景

- 手术辅助（达芬奇手术机器人）
- 康复机器人
- 护理辅助
- 药品配送
- 消毒 / 配送

### 代表企业

| 企业 | 国家 | 方向 |
|------|------|------|
| Intuitive Surgical | 美国 | 达芬奇手术机器人 |
| Stryker | 美国 | Mako 骨科机器人 |
| 天智航 | 中国 | 骨科手术机器人 |
| 微创医疗机器人 | 中国 | 多科室手术机器人 |
| 傅利叶智能 | 中国 | 康复机器人 |

### 落地节奏

- 2025-2027：手术机器人继续主导
- 2027-2030：康复机器人、护理机器人规模化
- 2030+：人形护理机器人（情感交互 + 物理辅助）

### 关键挑战

- 监管严格（NMPA、FDA）
- 临床数据积累周期长
- 医生培训成本高
- 单台价格高（百万级）

## 六、家庭服务

> 终极市场——但 ROI 计算困难。

### 典型场景

- 家务（清洁、做饭、洗衣）
- 陪伴（老人、儿童）
- 安防
- 园艺
- 助手

### 关键约束

| 维度 | 当前水平 | 商业化要求 |
|------|----------|------------|
| 价格 | 10-30 万美元 | < 3 万美元 |
| 任务泛化 | 单一任务 | 多任务 |
| 安全性 | 实验室级别 | 家庭可接受 |
| 维护 | 专业人员 | 消费者自维护 |

### 关键时间窗口

- 2026-2028：1X Neo、Sanctuary 等公司推出家庭原型
- 2028-2030：试点进入家庭
- **2030+：开始规模化爆发**

### 投资逻辑

> 家庭服务是 **"诗和远方"**——空间极大但兑现时间最长。

**提前布局的方式**：

- 关注 **1X Neo** 量产时间表
- 关注 **优必选 Walker** 家庭版本
- 关注 **Figure 家用版**（待发布）
- 关注 **宇树 G1 家庭版**（待发布）

## 十、核心投资逻辑

> **场景决定销量，销量决定产业链**——L7 是 L0-L6 的"需求源"。

**核心洞察**：

1. **2025-2028 看制造 + 物流**——这两个场景贡献 70% 以上的人形机器人销量。
2. **2028-2030 看医疗**——单价高、监管通过后爆发。
3. **2030+ 看家庭**——市场最大，但需要技术 + 价格 + 安全三重突破。

**A 股关联公司**：

- **制造场景**：汇川技术、埃斯顿、绿的谐波（通过 Tesla / Figure / 国内 OEM）
- **物流场景**：海康机器人（拟分拆）、极智嘉（已上市）、京东物流
- **商业服务**：普渡科技、擎朗智能、高仙
- **医疗场景**：天智航（688277）、微创医疗机器人（2252.HK）、傅利叶

---

## 十一、风险点

1. **落地不及预期**：客户付费意愿、场景复杂度可能拖累落地速度。
2. **价格下行幅度慢于预期**：硬件成本下降曲线比想象缓慢。
3. **安全 / 监管事件**：一次严重的机器人安全事故可能延缓整个行业。
4. **人力成本反向变化**：经济周期下人力成本下降，机器人 ROI 削弱。

---

## 十二、小结

- L7 是 **产业链的"需求源"**——所有 L0-L6 的投资最终都要靠 L7 兑现。
- 投资优先级：**制造业 + 物流仓储**（最确定）→ **商业服务 + 医疗**（中等确定）→ **家庭服务**（长期持有）。
- 二级市场最稳妥的参与方式：**通过 L1（零部件）+ L6（OEM 供应链）间接分享场景红利**。
