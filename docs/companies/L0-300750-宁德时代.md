## 四、产业链位置

**层级**：L0 资源材料层（电池材料 + 电池本体）
**细分赛道**：动力 + 储能 + 机器人电池
**产业链卡位**：全球电池绝对龙头

- **上游**：锂、钴、镍、磷酸铁锂
- **下游**：新能源车、储能电站、机器人
- **竞争格局**：
  - 全球：宁德时代、LG 新能源、比亚迪、松下
  - 国内：宁德时代（绝对龙头）、比亚迪、中创新航

## 六、投资逻辑

**一句话**：全球动力电池绝对龙头，机器人移动电源潜在受益方。

**详细逻辑**：
1. **基本盘稳健**：全球动力电池市占率 35%+，盈利能力领先
2. **储能第二曲线**：储能电池高速增长
3. **机器人电池弹性**：移动机器人、人形机器人对高能量密度电池需求增加
4. **固态电池前沿**：下一代电池技术储备
