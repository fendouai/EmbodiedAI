## 二、核心产品线

| 产品系列 | 规格 | 应用 |
|----------|------|------|
| **数控机床** | 加工中心、车床、磨床 | 工业母机 |
| **RV 减速器** | 通用 + 大负载 | 工业机器人、人形机器人 |
| **丝杠 / 直线导轨** | 滚珠丝杠、行星滚柱丝杠（在研） | 机床进给、人形机器人线性关节 |
| **刀具** | 数控刀具 | 机床配套 |
| **铸件** | 精密铸件 | 内部配套 |
| **子公司汉江机床** | 滚柱丝杠副、直线导轨 | 中高端数控机床、人形机器人 |

**RV 减速器**：公司 RV 减速器国内最早布局，2010 年代开始量产，目前是国内主要 RV 供应商之一。

## 四、产业链位置

**层级**：L1 核心零部件层
**细分赛道**：RV 减速器 + 丝杠 + 机床
**产业链卡位**：国资机器人基础工业平台

- **上游**：铸件、特种钢、控制系统
- **下游**：工业机器人厂、人形机器人（送样）、机床厂
- **竞争格局**：
  - RV：双环传动（领先）、Nabtesco（国际）
  - 丝杠：恒立、贝斯特、NSK、THK

## 五、核心客户 & 竞争对手

**核心客户**：
- 工业机器人厂
- 机床厂
- 国防军工
- 人形机器人 OEM（送样阶段）

**核心竞争对手**：
- RV：双环传动（民营，效率更高）、Nabtesco（日本）
- 机床：海天精工、纽威数控、亚威股份

## 六、投资逻辑

**一句话**：国资机器人基础工业平台 + RV/丝杠/机床三卡位，"长坡厚雪"型标的。

**关键看点**：
1. **国资背景**：陕西国资，机器人产业链国产替代受益方
2. **RV 减速器**：已批量供货，2026-2027 年随人形机器人量产放量
3. **丝杠业务**：汉江机床的滚柱丝杠副已基本可以满足中高端数控机床要求，公司已具备行星结构滚柱丝杠生产能力

## 七、风险点

1. **国企效率问题**：公司治理与民营有差距
2. **利润薄**：毛利率 17-18%，净利率 1.5%，弹性有限
3. **RV 减速器竞争**：双环传动等民营对手更高效
4. **数据待验证**：财务数据以年报披露为准
