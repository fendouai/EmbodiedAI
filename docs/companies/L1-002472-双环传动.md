## 四、产业链位置

**层级**：L1 核心零部件层
**细分赛道**：RV 减速器 + 新能源车齿轮
**产业链卡位**：齿轮是"工业的基石"，公司横跨工业机器人 + 新能源车双赛道

```
L0 特种钢（抚顺特钢、轴承钢）
   ↓
L1 齿轮加工 → RV 减速器（双环传动）★ 本报告
   ↓
L6 工业机器人（发那科、库卡）/ 新能源车（特斯拉、比亚迪）/ 人形机器人
   ↓
L7 制造 / 汽车 / 物流
```

- **上游**：轴承钢、特种钢（抚顺特钢）、数控磨齿机
- **下游**：新能源车厂（特斯拉、比亚迪、Stellantis）、工业机器人（与新松合作）、人形机器人 OEM
- **竞争格局**：
  - 国际：Nabtesco（日本）—— RV 减速器全球第一（60%+ 市占率）
  - 国内：双环传动（第一）、秦川机床、中大力德

## 五、核心客户 & 竞争对手

**核心客户**：
- 新能源车：特斯拉、比亚迪、广汽、Stellantis（匈牙利）
- 国际 Tier 1：采埃孚、麦格纳
- 工业机器人：新松机器人
- 智能执行机构：国内扫地机头部品牌、国内 Ebike 头部
- 海外：欧洲大客户（通过匈牙利工厂）

**核心竞争对手**：
- Nabtesco（日本）—— RV 减速器全球龙头
- Spinea（斯洛文尼亚）—— RV 次席
- 秦川机床（000837）—— RV 减速器国产化
- 中大力德（002896）—— RV + 谐波

**竞争优劣势**：
- 优势：齿轮加工精度全球前列（4-6 级），客户深度绑定；RV 减速器已配套国内一线机器人客户；海外产能（匈牙利 + 越南）即将释放
- 劣势：RV 减速器相比 Nabtesco 在精度、寿命仍有差距；新能源车齿轮面临价格压力

## 六、投资逻辑

**一句话**：双轮驱动（新能源车齿轮 + 机器人减速器）+ 海外产能释放——精密齿轮平台型公司。

**详细逻辑**：
1. **新能源车齿轮基本盘**：全球新能源车齿轮外包率持续提升，公司绑定特斯拉/比亚迪/采埃孚/麦格纳，2025 年新能源齿轮营收 +21.72%
2. **机器人减速器弹性**：环动科技 RV 减速器已配套国内一线机器人客户，2025 年减速器业务 +35.8%
3. **海外产能释放**：匈牙利工厂 2026 年 2 月正式投产，复制国内齿轮外包路径
4. **智能执行机构第二曲线**：扫地机 + 智能汽车 + Ebike 三大新场景

**催化剂**：
- 匈牙利工厂海外订单放量
- 人形机器人 RV 减速器订单
- 与新松等机器人 OEM 合作落地

## 七、风险点

1. **新能源车销量风险**：国内新能源车 2026 Q1 销量分化（小米 +7%、理想 +2%、广汽埃安 +57%），大客户依赖
2. **原材料波动**：钢材价格波动直接影响齿轮毛利率
3. **海外建厂风险**：匈牙利、越南工厂产能爬坡可能慢于预期
4. **RV 减速器价格战**：国产 RV 替代加速，价格压力
5. **应收账款风险**：2025 年末应收账款较高，海外大客户信用周期长
