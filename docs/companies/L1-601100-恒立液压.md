## 四、产业链位置

**层级**：L1 核心零部件层
**细分赛道**：行星滚柱丝杠 + 液压元件
**产业链卡位**：工程机械液压龙头 + 机器人丝杠弹性，是"传统周期股 + 机器人新经济"双重身份

```
L0 特种钢 / 铸件
   ↓
L1 液压元件 / 行星滚柱丝杠（恒立液压）★ 本报告
   ↓
L6 工程机械 / 人形机器人线性关节
   ↓
L7 工程基建 / 制造
```

- **上游**：特种钢、铸件、电机
- **下游**：
  - 传统：挖掘机厂商（三一、徐工、柳工、卡特彼勒等）、装载机、起重机
  - 新增：人形机器人线性关节（送样北美客户，推测为特斯拉）
- **竞争格局**：
  - 液压件国际：博世力士乐（德国）、川崎重工（日本）、伊顿（美国）
  - 丝杠国际：Rollvis（瑞士）、SKF、NSK、THK
  - 国产：恒立液压（绝对龙头）、艾迪精密

## 五、核心客户 & 竞争对手

**核心客户**：
- 国内挖掘机：三一重工、徐工机械、柳工、龙工
- 国际挖掘机：卡特彼勒、约翰迪尔、沃尔沃（通过海外工厂配套）
- 北美机器人客户（推测为 Tesla Optimus 线性关节）
- 其他：盾构机、装载机、起重机厂商

**核心竞争对手**：
- 博世力士乐（德国）—— 液压件全球龙头
- 川崎重工（日本）—— 液压 + 工程机械
- 博世力士乐 / 林德（德国）—— 液压件
- Rollvis（瑞士）—— 行星滚柱丝杠全球领先
- 国产丝杠：贝斯特（300580）、五洲新春（603667）、鼎智科技（873593）

**竞争优劣势**：
- 优势：液压件领域绝对龙头（国内市占率第一）；丝杠业务从 0 到 1 突破，2025 年已送样北美客户（推测 Tesla）
- 劣势：传统工程机械业务面临周期下行（地产 + 基建）；丝杠业务从 0 起步，业绩兑现需时间

## 六、投资逻辑

**一句话**：工程机械基本盘 + 丝杠业务从 0 到 1——"传统价值 + 机器人成长"双击。

**详细逻辑**：
1. **工程机械出海对冲国内周期**：公司 2025 年海外业务持续推进（墨西哥工厂、匈牙利工厂），对冲国内挖掘机周期下行
2. **液压件高端化**：从挖掘机油缸向泵阀马达、再向工业自动化液压系统升级
3. **丝杠业务弹性**：行星滚柱丝杠是人形机器人核心卡位（单台用量 14-28 根，单价 1000-5000 元），公司 2025 年已送样北美客户
4. **市场空间**：2030 年人形机器人丝杠市场预计 300-500 亿元，公司若进入 Tesla 链，业绩弹性巨大

**催化剂**：
- 北美客户（Tesla）正式订单确认
- 丝杠产能爬坡数据
- 匈牙利工厂海外业务放量

## 七、风险点

1. **工程机械周期下行**：国内挖掘机销量受地产 + 基建拖累，2025 年下游需求疲软
2. **丝杠业务兑现不及预期**：从送样到量产有时间窗口，过程中估值波动大
3. **海外建厂风险**：墨西哥 / 匈牙利工厂产能爬坡
4. **估值高位**：PE TTM 约 50x，市场对丝杠业务预期较高
5. **原材料波动**：钢材价格直接影响毛利率
