## 六、投资逻辑

**一句话**：轴承主业稳健 + 丝杠新业务弹性，估值合理。

**关键看点**：
1. **轴承基本盘**：汽车 + 风电轴承市占率提升
2. **丝杠新业务**：2025-2026 年有望成为新增长点
3. **新能源汽车**：轴承需求受益于新能源车销量
4. **估值合理**：相比纯机器人标的估值更合理

## 七、风险点

3. **风电装机波动**：风电轴承业务受装机量影响
