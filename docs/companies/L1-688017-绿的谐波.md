- 寿命：> 10,000 小时
- 扭矩范围：0.5 N·m ~ 50 N·m（人形机器人主流 5-30 N·m）

## 四、产业链位置

**层级**：L1 核心零部件层
**细分赛道**：谐波减速器
**产业链卡位**：人形机器人 + 协作机器人 + 工业机器人 **共用核心部件**

```
L0 稀土永磁（中科三环等）
   ↓
L1 谐波减速器（绿的谐波） ★ 本报告
   ↓
L6 协作机器人 / 人形机器人 / 工业机器人
   ↓
L7 制造 / 物流 / 医疗
```

- **上游**：稀土永磁（用于电机）、轴承钢、特种钢
- **下游**：协作机器人厂商（越疆、节卡、遨博）、人形机器人（特斯拉 Optimus、Figure、国内智元、宇树、优必选）、工业机器人（埃斯顿、新松）
- **竞争格局**：
  - 国际：Harmonic Drive Systems（日本）—— 谐波减速器全球绝对龙头，毛利率 50%+
  - 国内：绿的谐波、来福、大族（谐波）、汉宇集团
  - 绿的国内市占率估算 > 60%

## 五、核心客户 & 竞争对手

**核心客户**：
- 国际：Universal Robots（协作机器人）、KUKA、ABB
- 国内协作机器人：越疆、节卡、遨博、大族机器人
- 国内人形机器人：优必选、智元、银河通用、宇树
- 海外人形机器人：Tesla（送样阶段）、Figure AI（送样阶段）

**核心竞争对手**：
- Harmonic Drive Systems（日本）—— 全球龙头，技术领先
- Nidec-Shimpo（日本）—— 工业级谐波
- 北京谐波（来福谐波，未上市）—— 国产
- 大族激光（002008）旗下谐波业务

**竞争优劣势**：
- 优势：国内市占率第一，量产能力，具身智能机器人客户卡位
- 劣势：相比 Harmonic Drive 在高端精度、寿命上仍有差距；毛利率从 41% 下降至 37% 反映价格战压力

## 六、投资逻辑

**一句话**：人形机器人量产 + 国产谐波替代 + 具身智能弹性——"卖铲人"中最纯的标的。

**详细逻辑**：
1. **行业 β**：人形机器人单台谐波减速器用量 14-30 个，是工业机器人的 3-5 倍；2026-2030 行业销量 CAGR > 100%
2. **公司 α**：国内谐波减速器龙头，市占率 > 60%，已经进入 Tesla / Figure / 优必选 / 智元 / 宇树等头部 OEM 供应链
3. **业绩拐点**：2025 年净利润 +121%，毛利率虽下滑但净利率提升至 21.79%，规模效应开始释放
4. **新业务**：机电一体化执行器、球形电机（研发中）打开第二曲线

**催化剂**：
- Tesla Optimus 量产时间表
- 优必选 / 智元 / 宇树销量数据
- 球形电机 / 集成关节模组新品发布

## 七、风险点

1. **价格战风险**：谐波减速器国产替代加速，毛利率从 41% 降至 37%
2. **大客户依赖**：单一大客户（如 Tesla、宇树）订单波动会显著影响业绩
3. **技术路线风险**：球形电机、柔性关节等新技术可能颠覆传统谐波
4. **估值高位**：PE TTM > 400x，对 2026-2027 业绩预期极度乐观
5. **产能扩张节奏**：智能制造项目 + 募投项目是否能按时投产决定增长持续性
