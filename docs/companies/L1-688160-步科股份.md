## 四、产业链位置

**层级**：L1 核心零部件层
**细分赛道**：无框力矩电机
**产业链卡位**：人形机器人关节直驱核心

```
L0 稀土永磁 / 绝缘材料
   ↓
L1 无框力矩电机（步科股份）★ 本报告
   ↓
L6 人形机器人 / 协作机器人
   ↓
L7 制造 / 家庭
```

- **上游**：稀土永磁（中科三环等）、绝缘材料、轴承
- **下游**：人形机器人（Tesla / 优必选 / 智元 / 银河通用 / 宇树）、协作机器人
- **竞争格局**：
  - 国际：Maxon（瑞士）、Kollmorgen（美国）、Allied Motion（美国）
  - 国内：步科股份、鸣志电器、伟创电气

## 五、核心客户 & 竞争对手

**核心客户**：
- 国内人形机器人：优必选、智元机器人、银河通用、宇树科技
- 国内协作机器人：越疆、节卡
- 工业自动化：3C、锂电、半导体设备厂商

**核心竞争对手**：
- Maxon（瑞士）—— 无框电机全球高端
- Kollmorgen（美国）—— 工业级
- 鸣志电器（603728）—— 步进 + 无框
- 伟创电气（688698）—— 工控 + 机器人电机

**竞争优劣势**：
- 优势：从工控到机器人的全栈布局；与汇川合作（iFG 平台）；无框电机量产能力
- 劣势：相比 Maxon 在高端精度、寿命上仍有差距；人形机器人收入占比小，业绩兑现需时间

## 六、投资逻辑

**一句话**：无框力矩电机国产替代 + 人形机器人从 0 到 1 突破——机器人"心脏"供应商。

**详细逻辑**：
1. **国产替代**：Maxon / Kollmorgen 等国际品牌价格高、交付慢，国产替代窗口
2. **人形机器人弹性**：单台用量 28-40 个，市场空间 2026 年 5-10 亿元，2030 年 50-100 亿元
3. **工控基本盘**：传统工控业务稳健，提供现金流
4. **软件协同**：与汇川合作 iFG 平台，工业 AI 软件能力

**催化剂**：
- 人形机器人 OEM 订单确认
- 单台机器人电机用量提升
- 国产替代加速

## 七、风险点

1. **人形机器人量产时间表**：2026-2027 年量产时间表反复推迟会影响业绩
2. **价格战**：无框电机新进入者较多
3. **大客户依赖**：单一人形机器人 OEM 客户订单波动大
4. **技术路线**：端到端 VLA 路线可能改变对无框电机的需求结构
5. **数据待验证**：上述财务数据为公开信息估算，建议以公司正式年报为准
