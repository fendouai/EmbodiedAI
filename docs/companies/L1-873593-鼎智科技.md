## 四、产业链位置

**层级**：L1 核心零部件层
**细分赛道**：微特电机 + 微型丝杠
**产业链卡位**：人形机器人"小关节"专家

- **上游**：特种钢、铜线、电子元器件
- **下游**：
  - 医疗：医疗器械厂
  - 机器人：人形机器人 OEM（送样/小批量）

## 五、核心客户 & 竞争对手

**核心客户**：
- 医疗：医疗器械厂商（呼吸机、注射泵、康复设备）
- 机器人：人形机器人 OEM
- 工业自动化：通用工业

**核心竞争对手**：
- 丝杠：恒立、贝斯特、NSK、THK
- 微特电机：鸣志电器、江苏雷利、Maxon、Faulhaber

## 六、投资逻辑

**一句话**：微特电机 + 丝杠垂直整合，机器人小关节专家。

**关键看点**：
1. **产品矩阵**：电机 + 丝杠 + 编码器一体化
2. **医疗稳健**：医疗电机基本盘稳健
3. **机器人弹性**：灵巧手关节模组受益人形机器人
4. **江苏雷利协同**：母公司供应链支持

## 七、风险点

1. **规模较小**：总市值和营收规模相对小
2. **客户集中**：单一 OEM 客户订单波动
3. **数据待验证**
