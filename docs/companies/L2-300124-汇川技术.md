## 四、产业链位置

**层级**：L2 控制系统层（核心）+ L1 核心零部件层（机器人零部件）+ L6 机器人整机（解决方案）
**细分赛道**：通用工控 + 机器人零部件
**产业链卡位**：工控绝对龙头 + 机器人全栈布局

```
L0 稀土永磁 / IGBT
   ↓
L1 电机 / 减速器 / 编码器（汇川自研）
   ↓
L2 控制系统（汇川技术）★ 本报告
   ↓
L6 工业机器人 / 人形机器人
   ↓
L7 制造 / 商业 / 家庭
```

- **上游**：稀土永磁、IGBT、控制芯片
- **下游**：
  - 工控：3C、锂电、半导体、机床、风电
  - 新能源车：小米、理想、广汽埃安、奇瑞
  - 机器人：人形机器人 OEM（已获头部定点）

## 五、核心客户 & 竞争对手

**核心客户**：
- 工控：3C、锂电、半导体设备厂
- 新能源车：小米、理想、广汽埃安、奇瑞、Stellantis（海外）
- 电梯：康力、广日、上海三菱
- 机器人：国内头部人形机器人企业

**核心竞争对手**：
- 工控：西门子（德国）、三菱（日本）、汇川（国内）
- 伺服：安川（日本）、发那科（日本）
- 新能源车电控：特斯拉、华为车 BU

**竞争优劣势**：
- 优势：工控绝对龙头，多业务线协同；机器人全栈布局；海外业务加速（2025 计划 H 股上市）
- 劣势：新能源车业务承压；2026 Q1 净利润下滑

## 六、投资逻辑

**一句话**：工控基本盘 + 机器人全栈布局 + 海外扩张，国产自动化之王。

**详细逻辑**：
1. **工控龙头地位**：通用伺服 / 低压变频器市占率均第一
2. **机器人全栈**：从无框力矩电机到低压伺服到关节模组到丝杠到编码器全产业链覆盖
3. **人形机器人定点**：已获国内头部企业定点，业务增长可期
4. **AI 工业软件**：iFG 平台，从硬件向软硬件结合转型

**催化剂**：
- 人形机器人 OEM 定点放量
- A+H 上市完成
- 海外业务（欧洲、东南亚）放量
- 通用自动化业务拐点

## 七、风险点

2. **机器人业务兑现时间表**：从定点到大规模量产需要时间
3. **工控价格战**：自动化行业竞争激烈
