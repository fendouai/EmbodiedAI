## 二、核心产品线

| 产品系列 | 规格 | 应用 |
|----------|------|------|
| **NOR Flash** | 4Mb ~ 1Gb | 嵌入式、物联网 |
| **MCU** | ARM Cortex-M 系列 | 工业控制、机器人 |
| **NAND Flash** | SLC / SPI NAND | 嵌入式存储 |
| **DRAM** | DDR3 / DDR4 | 利基型 DRAM |
| **传感器** | 触控、指纹 | 消费电子 |
| **车规芯片** | 通过 AEC-Q100 | 汽车电子 |
