## 一、公司概况

| 项目 | 信息 |
|------|------|
| 公司全称 | Agility Robotics |
| 总部 | 美国俄勒冈州 |
| 成立 | 2015 年 |
| 创始人 | Damion Shelton、Jonathan Hurst（Oregon State University） |
| 主营业务 | 仓储物流人形机器人 |
