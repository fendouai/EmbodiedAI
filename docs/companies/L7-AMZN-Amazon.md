## 一、公司概况

| 项目 | 信息 |
|------|------|
| 公司全称 | Amazon.com, Inc. |
| 股票代码 | AMZN（NASDAQ） |

## 二、核心产品线（机器人相关）

| 产品系列 | 规格 | 应用 |
|----------|------|------|
| **Kiva（已改名 Amazon Robotics）** | 仓储 AMR | Amazon 仓储 |
| **Agility Digit** | 人形机器人 | Amazon 仓储（投资 Agility） |
| **Proteus** | 自主移动机器人 | 仓储 |
| **Cardinal** | 拣选机器人 | 仓储 |
| **Sparrow** | 拣选臂 | 仓储 |
| **Drone Delivery** | Prime Air | 末端配送 |
| **AWS** | 云计算 | AI 训练 |

## 三、产业链位置

**层级**：L7 应用场景层
**细分赛道**：智能物流
**产业链卡位**：全球最大物流机器人部署方

## 四、核心优势

1. **全球最大 AMR 部署**：Kiva 系机器人已超百万台
2. **Agility 投资**：人形机器人进入仓储
3. **AWS 算力**：自用 + 对外
4. **自研机器人**：Proteus、Cardinal、Sparrow

## 五、投资逻辑（机器人部分）

**一句话**：全球最大物流机器人客户 + 自研 + 投资 Agility，机器人最大"客户"之一。

## 六、风险点

1. 电商增速放缓
2. AWS 竞争
3. 机器人 ROI 验证
4. 美中科技博弈
